## 📂 Repository Structure

Each topic folder contains practice code, worked examples, and revision notes.

| Topic | Description |
|---|---|
| `variables-and-data-types/` | Primitives, type casting, scope |
| `control-flow/` | Conditionals, loops, comprehensions |
| `functions/` | Definitions, args/kwargs, lambdas, decorators |
| `data-structures/` | Lists, tuples, dicts, sets |
| `error-handling/` | Try/except, custom exceptions |
| `file-handling/` | Read/write, context managers, file modes |
| `modules-and-packages/` | Imports, `__init__`, pip, virtual environments |
| `oop/` | Classes, inheritance, polymorphism, dunder methods |
